# Introduction

RoUI3 is a feature-rich and elegant animation plugin used to create beautiful UI animations for use in your games. It is simple to use but very powerful. The documentation will take you through everything you need to know from the basics to more advanced concepts. 

## Plugin vs. Animation Module
The RoUI3 plugin is what you actually use to create your animations. This is where you edit keyframes, easing styles, directions, etc. and put together everything. When you're done you'll export your animation.

This is where the RoUI3 animation module comes into play. It is what you use to actually play your animations.

## Installation
The recommended method of installation is by [purchasing RoUI3](https://create.roblox.com/store/asset/11798243393/RoUI3) directly from the Roblox Creator Store. This will keep you up to date with the plugin and the module (as long as you download the module using the plugin). It also supports the development of RoUI3.
