RoUI3Animation

A RoUI3 animation class.

Functions​

UseKeyframeTransformer​

</>
RoUI3Animation:UseKeyframeTransformer(transformer: RoUI3KeyframeTransformer) → ()

Sets a keyframe transformer to use that alters keyframe values when they are generated via :PreloadAnimation(). As a result you must set the transformer before any preloading is done or the keyframe's values will never be properly mapped.

PreloadAnimation​

</>
RoUI3Animation:PreloadAnimation() → ()

Preloads an animation by internally generating it's tracks, keyframe values, and tweens.

WithOptions​

</>
RoUI3Animation:WithOptions(options: RoUI3AnimationOptions) → RoUI3Animation

Sets the options to use when the animation is played and returns the updated animation.

BindToEvent​

</>
RoUI3Animation:BindToEvent(
event: string,
trigger: Instance,
callback: (() → ())?
) → () → ()

Binds an event of a trigger instance to play an animation. Can pass an optional callback to be called when the event is triggered. If you do pass this paremeter you must :Play() the animation yourself. Returns a function that can be used to clean up the event connection.

Completed​

</>
RoUI3Animation:Completed(callback: () → ()) → ()

Sets a callback to be called when the animation completes playing.

RemoveMarker​

</>
RoUI3Animation:RemoveMarker(id: string) → ()

Removes a marker from the given id.

SetTarget​

</>
RoUI3Animation:SetTarget(target: Instance) → ()

Sets a target that the animation will execute upon when played. For standard animations your target should be the ScreenGui you edited when creating your animation with the RoUI3 plugin.

Warning: If your animation is a template animation this method will replace all other targets.

Wait​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>

</>
RoUI3Animation:Pause() → ()

ResetTargets​

</>
RoUI3Animation:ResetTargets() → ()

Resets all targets to their initial states before the animation played. The initial state used is cached whenever :PreloadAnimation() is called.

Reset​

</>
RoUI3Animation:Reset() → ()

Resets almost the entire animation's state so it can be reused. The following is preserved when this method is called:

  1. Targets
  2. Animation Options
  3. Set Keyframe Transformer
  4. Bound Events
  5. Completed Callback
